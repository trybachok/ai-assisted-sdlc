# [ОБЯЗАТЕЛЬНЫЙ] string. Идентификатор навыка: только строчные латинские буквы,
# цифры и дефисы. Должен совпадать с именем папки, в которой лежит SKILL.md
# (здесь: my-skill/). По этому имени навык вызывают вручную: /my-skill.
name: my-skill

# [ОБЯЗАТЕЛЬНЫЙ] string. Что делает навык и когда его использовать. По этому
# описанию агент решает, подходит ли навык к задаче, поэтому пишите конкретно:
# результат, ситуации и формулировки запросов. Без description агент вряд ли
# выберет навык сам (вызвать по имени всё равно можно), а в Cloud Agents такой
# навык показывает предупреждение.
description: >-
  Кратко: что делает навык и какой результат создаёт. Использовать, когда
  пользователь просит о конкретной задаче или упоминает конкретные слова.

# [необязательный] string | array. Шаблоны файлов (glob), ограничивающие навык:
# он предлагается агенту, только когда тот читает или правит подходящие файлы.
# Можно задать списком (как здесь) или одной строкой через запятую:
#   paths: "**/*.ts, src/**/*.tsx"
# УДАЛИТЕ поле, если навык должен быть доступен при работе с любыми файлами.
# Устаревшее поле globs ещё принимается для старых навыков, но в новых
# используйте paths. Навыку из вложенной папки проекта (например,
# apps/web/.cursor/skills/) paths не нужен: он и так ограничен этой папкой.
paths:
  - "**/*.ts"
  - "src/**/*.tsx"

# [необязательный] boolean. По умолчанию false: агент сам применяет навык, когда
# считает его уместным. true — навык подключается только при явном вызове
# /my-skill, как обычная слэш-команда.
disable-model-invocation: false

# [необязательный] string. Иконка значка, когда навык используется как Custom
# Mode (навык остаётся в контексте на всю сессию). Имена из набора иконок
# Cursor, например: code, terminal, bug, git-branch, book-open, beaker, shield,
# rocket. По умолчанию — молния; неизвестное имя тоже даёт молнию.
icon: rocket

# [необязательный] string. Цвет значка в режиме Custom Mode. Одно из значений:
# default, green, cyan, blue, purple, magenta, orange, yellow, red, brand.
# Неизвестное значение заменяется значком по умолчанию.
color: green

# [необязательный] object. Произвольные пары «ключ — значение» с дополнительными
# сведениями о навыке. Набор ключей не регламентирован; ниже — примеры.
metadata:
  version: "1.0.0"
  owner: platform-team
