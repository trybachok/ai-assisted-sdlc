# Шаблон навыка Cursor

Папка-шаблон для создания навыка (Agent Skill) по официальной документации:
[Agent Skills](https://cursor.com/docs/skills).

Шаблон — папка [`my-skill/`](my-skill/). В ней есть все файлы и папки, которые
описывает документация, а в `SKILL.md` — все поля конфигурации. У каждого поля
есть комментарий: для чего оно и обязательно ли оно (`[ОБЯЗАТЕЛЬНЫЙ]` или
`[необязательный]`).

## Структура

```text
templates/skill/
├── my-skill/                    # шаблон: папка навыка
│   ├── SKILL.md                 # ОБЯЗАТЕЛЬНЫЙ: настройки и инструкции навыка
│   ├── scripts/                 # необязательная: код, который запускает агент
│   │   └── example.sh
│   ├── references/              # необязательная: документация по требованию
│   │   └── REFERENCE.md
│   └── assets/                  # необязательная: шаблоны, изображения, данные
│       └── report-template.md
├── SKILL.template.md            # заготовка тела навыка с готовыми разделами
└── README.md                    # этот файл (в навык не копируется)
```

Обязателен только `SKILL.md`, а в нём — только поля `name` и `description`.
Папки `scripts/`, `references/` и `assets/` необязательны: ненужные удалите.

Комментарии лежат в самих файлах: в [`SKILL.md`](my-skill/SKILL.md) — в
YAML-frontmatter (строки с `#`), в остальных — в начале файла.

## Поля `SKILL.md`

| Поле | Обязательное | Назначение |
| --- | --- | --- |
| `name` | да | Идентификатор: строчные буквы, цифры, дефисы. Совпадает с именем папки навыка |
| `description` | да | Что делает навык и когда его использовать. По нему агент выбирает навык |
| `paths` | нет | Glob-шаблоны файлов, при работе с которыми навык предлагается агенту |
| `disable-model-invocation` | нет | `true` — навык подключается только по явному вызову `/имя-навыка` |
| `icon` | нет | Иконка значка, когда навык используется как Custom Mode |
| `color` | нет | Цвет значка в режиме Custom Mode |
| `metadata` | нет | Произвольные пары «ключ — значение» |

## Как пользоваться шаблоном

1. Скопируйте папку `my-skill/` в папку навыков (см. таблицу ниже) под именем
   своего навыка, например из корня этого репозитория:

   ```bash
   cp -R templates/skill/my-skill .cursor/skills/review-migrations
   ```

2. В `SKILL.md` задайте `name` — точно такое же, как имя папки
   (`review-migrations`).
3. Напишите `description`: что делает навык и в каких ситуациях его применять.
4. Удалите необязательные поля, которые не нужны. Особенно `paths`: пока оно
   задано, навык предлагается только при работе с файлами по этим шаблонам.
5. Замените тело `SKILL.md` своими инструкциями. Развёрнутая заготовка разделов
   («Цель», «Входные данные», «Порядок выполнения» и др.) —
   в [`SKILL.template.md`](SKILL.template.md).
6. Замените или удалите примеры в `scripts/`, `references/`, `assets/`. Если
   оставляете скрипты, сделайте их исполняемыми: `chmod +x scripts/*`.
7. Удалите поясняющие комментарии, когда они перестанут быть нужны.

## Куда класть навык

Cursor автоматически находит навыки в этих папках:

| Папка | Область действия |
| --- | --- |
| `.cursor/skills/` | Проект |
| `.agents/skills/` | Проект |
| `~/.cursor/skills/` | Пользователь: все проекты на этой машине |
| `~/.agents/skills/` | Пользователь: все проекты на этой машине |

Для совместимости Cursor также читает `.claude/skills/`, `.codex/skills/`,
`~/.claude/skills/` и `~/.codex/skills/`.

Папки навыков можно группировать во вложенные папки-категории
(`.cursor/skills/shipping/land-it/SKILL.md`): имя навыка определяет папка,
в которой лежит `SKILL.md`, а не категория.

## Проверка

1. Откройте **Customize** в боковой панели и перейдите в раздел **Skills**:
   навык должен появиться в списке.
2. В чате агента наберите `/` и имя навыка — так навык вызывается вручную.

## Как поделиться навыком

Сами по себе навыки из репозитория не импортируются: их упаковывают в плагин
и публикуют через маркетплейс. Шаблон плагина —
[`templates/plugin/`](../plugin/README.md), инструкция —
[`docs/cursor-plugin.md`](../../docs/cursor-plugin.md). На тарифах Teams и
Enterprise личный навык из `~/.cursor/skills/` можно опубликовать для команды
кнопкой **Publish** в Customize → Skills.
