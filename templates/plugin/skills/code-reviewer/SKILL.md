# Ревью кода

Замените этот текст своими инструкциями. Тело файла — это указания агенту:
оно попадает в контекст, когда навык применяется.

## Когда использовать

- Пользователь просит провести ревью кода или pull request.
- Нужно оценить качество изменений перед слиянием.

## Порядок работы

1. Определить объём изменений: какие файлы и строки затронуты.
2. Проверить корректность: логические ошибки, граничные случаи, обработку ошибок.
3. Проверить безопасность: инъекции, секреты в коде, проверку входных данных.
4. Проверить соответствие стандартам проекта и наличие тестов.
5. Сообщить о находках по убыванию важности, указывая файл и строку.

## Правила

- Не придумывать проблемы: каждую находку подтверждать ссылкой на код.
- Если требования неясны, задать пользователю уточняющий вопрос.

Держите SKILL.md кратким: подробные справочные материалы выносите в
`references/`, скрипты — в `scripts/` и ссылайтесь на них относительными путями
от папки навыка (например, `scripts/validate.py`).
