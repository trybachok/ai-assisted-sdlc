# =============================================================================
# ШАБЛОН READ-ONLY SUBAGENT: субагент только для чтения. Он изучает проект
# и сообщает о находках, но ничего не изменяет. Ограничение включает
# настройка readonly со значением true.
# Документация: https://cursor.com/docs/subagents#configuration-fields
#
# Как пользоваться:
#   1. Скопируйте файл в папку .cursor/agents своего проекта (субагент для
#      проекта) или в ~/.cursor/agents (личный субагент для всех проектов)
#      и переименуйте: имя файла — это имя субагента, например
#      security-auditor.md.
#   2. Впишите свои name и description. Строку readonly не изменяйте.
#   3. Под блоком настроек замените текст в квадратных скобках своим заданием.
#      Субагент не видит переписку основного агента: всё, что ему нужно
#      знать, напишите в задании или укажите, какие файлы прочитать.
#   4. Строки с пояснениями (они начинаются с #) можно удалить.
#
# Подходит для ревью, аудита и поиска — задач, где результат — отчёт. Если
# субагент должен исправлять код или запускать команды, которые записывают
# файлы, возьмите шаблон project-subagent.md.
#
# Как записывать настройки: каждая — в одну строку и без кавычек. Не
# дописывайте пояснение после значения: Cursor прочитает настройку неверно,
# и ограничение «только чтение» не включится.
# =============================================================================

# [указывайте всегда] Имя субагента: строчные латинские буквы и дефисы. По нему
# субагента вызывают в чате, например /security-auditor. Должно совпадать
# с именем файла; без этой настройки Cursor возьмёт имя из имени файла.
name: readonly-subagent

# [указывайте всегда] Что делает субагент и когда основной агент должен
# передавать ему задачу: по описанию агент решает, поручать ли работу. Пишите
# конкретно, в одну строку, без двоеточий и символа #. Слова «используй
# проактивно» подталкивают агента передавать задачу без напоминаний.
description: Что проверяет субагент и в каких задачах основной агент должен передавать ему работу

# [необязательный] Модель. inherit — та же, что у основного агента (значение
# по умолчанию). Вместо inherit можно указать ID модели из справочника:
# https://cursor.com/docs/models-and-pricing
model: inherit

# [ОБЯЗАТЕЛЬНЫЙ для этого типа] true — только чтение: субагент не изменяет
# файлы и не выполняет команды, меняющие состояние. Строка должна выглядеть
# в точности так.
readonly: true

# [необязательный] false — режим Foreground: основной агент ждёт результат
# (значение по умолчанию). true — режим Background: субагент работает в фоне.
is_background: false
